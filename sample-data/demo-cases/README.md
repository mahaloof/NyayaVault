# Fictional demonstration cases

Twelve purpose-written training documents across four realistic investigation scenarios. All organizations, identifiers, observations and dates inside the documents are fictional. The app generates genuine hashes, encryption, custody events and Fabric transactions when the documents are imported. No historical registration or transaction time is invented.

Import with `scripts/populate-demo.py`; reruns reuse matching evidence and do not duplicate completed actions. The old test cases are archived from normal views while their ledger proofs remain intact.
